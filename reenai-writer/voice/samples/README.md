# 样本索引

写作时语气拿不准，挑一篇同档位的读。归纳风格时，按类型分轻重。

- **原文**，作者自己写的。最能代表作者，权重最高。
- **亲改**，AI 起草、作者亲手改过的对照。改了什么就是在说作者要什么。
- **认可稿**，AI 起草、作者认可的版本。能看出方向，但它是 AI 眼里的作者，单靠它容易把风格拉平。
