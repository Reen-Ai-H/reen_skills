# 版本记录

## v0.5 · 2026-11-21 · 大修

- 结构拆成引擎（SKILL.md、references）、声音（voice）、迭代（evolution）三层，分享时只换 voice。
- profile 重写，八条正面写法，每条配作者的原句；新增放开、平实、正式三档语气；禁用项压成一节。
- 出处说明、认可范围、免责声明全部移出写作路径，放进 feedback-log。
- 新增 `scripts/check.py`，按 `voice/checks.txt` 查标点、词语、翻案句、连续反问和句长。
- 写作流程从四步加若干规则，简化为六步；新增「迭代」一节，记反馈和存样本不用先问。
- 合并旧的 content-methodology、quality-gates、edit-calibration、visual-planning、visual-feedback。
- 停用 khazix-writer，个人写作只保留这一个 Skill。
