# 反馈日志

每次合作的反馈按时间追加。写日期、场景、作者原话或改动对照，再写看出的规律。规律已经写进 profile 的，标上「已归纳 vX」。

模板

```
## YYYY-MM-DD · 作品或场景
原话 / 改动
规律（推测）
```

文件在 `/Users/makerzhu/Projects/self_media/output/macwin-article-2026-09-07/`。作者先口头说图一最好，随后纠正，最终选图三 `cover-c.png`（荧光黄绿底、极粗黑体大字、钴蓝立体箭头指向金属棋子、橙红刷痕和纸面颗粒）。图一 `cover-a.png`（奶油白底、键帽静物）不如图三。图二 `cover-b.png`（深蓝黑底、等距玻璃微缩场景）淘汰，原话「配图不合理，而且缺乏设计感」。
