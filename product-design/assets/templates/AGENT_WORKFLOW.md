# Agent workflow

1. Read `AGENTS.md`, this document, `PROGRESS.md`, and relevant product documents.
2. Inspect Git state and establish a tested baseline.
3. Work one evidence-bearing stage at a time.
4. Update `PROGRESS.md` after each stage.
5. Record true blockers and options in `BLOCKED.md`; continue unaffected work.
6. After three materially identical failures, stop that action and preserve evidence.
7. Require implementation, independent audit, and product/visual judgment to remain separate roles.
