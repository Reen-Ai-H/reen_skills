# Project agent instructions

## Product authority

- Read `docs/README.md` first.
- Treat `docs/PRODUCT_SPEC.md` as the current product answer.
- Record accepted product changes in `docs/DECISIONS.md` before implementation.

## Long-running work

- Read and update `PROGRESS.md`; put true blockers in `BLOCKED.md`.
- Preserve existing user work and data.
- Run the checks defined in `docs/ACCEPTANCE.md` before reporting completion.
- Never read, print, or commit secrets or `.env` values.
