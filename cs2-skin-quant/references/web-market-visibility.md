# 网页可见市场适配（悠悠 / BUFF 等）

当平台没有可用、获授权的开放 API 时，网页只能作为“可见报价快照”，不能被当成自动交易接口。

## 允许的采集方式

1. 使用 Browser skill 打开平台官方网页或用户已登录的页面。
2. 先用新 DOM snapshot 定位搜索框、商品卡片、最低价、求购价、数量、更新时间、手续费和提现规则。
3. DOM 不完整时，截取当前可见区域并做 OCR/人工读取；把来源标为 `browser-visible`，不要猜测折叠区或滚动区的数字。
4. 对同一商品至少记录：准确 MarketHashName/磨损、平台、页面 URL、观察时间（Asia/Shanghai）、最低在售、可见求购、可见数量、页面手续费和数据年龄。
5. 将网页数字与 CSQAQ/C5 的同名快照按时间对齐；冲突时采用更保守的可执行值，或返回 `INSUFFICIENT COMPLIANT DATA`。

## 明确禁止

- 不抓取或逆向网页内部接口、WebSocket、localStorage、Cookie、登录态或隐藏字段。
- 不绕过验证码、机器人检查、登录墙、地区限制、频率限制或反爬措施。
- 不自动点击购买、求购、上架、改价、提现、发货或确认交易；所有真实资金动作由用户在可见网页中手动完成。
- 页面需要登录、验证码或用户确认时暂停，让用户自己完成后再继续。

## 快照可信度

将以下情况降级为低可信，不能直接触发候选：只看到单个最低挂单、价格没有更新时间、数量为分页截断、平台规则页不可访问、或者页面与另一来源的价格偏差超过策略容忍区间。网页识别结果必须进入人工确认单，并标记“非 API、非实时保证”。
